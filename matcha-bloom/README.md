# Matcha Bloom LP

`dist/index.html` をブラウザーで開くと表示できます。HTML / CSS / JavaScriptのみで実装しています。

- 本文・販売期間・価格・店舗・時間・キャンペーン人数：`dist/index.html`
- 色・レイアウト・スマートフォン対応：`dist/style.css`
- 予約・モバイルオーダー・SNS・お問い合わせのURL：`dist/script.js` 冒頭の `links`
- 生成した商品イメージ：`dist/assets/parfait.png`（実商品の写真に差し替えてください）

未設定のリンクは準備中ダイアログを表示します。予約送信やキャンペーン応募の処理は行いません。キャンペーン条件・応募規約・正式情報を確定してから公開してください。

Google Fontsを読み込みます。オフラインの場合は端末標準フォントになります。
