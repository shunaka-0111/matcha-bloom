# Matcha Bloom

宇治抹茶と苺の季節限定パフェを紹介するレスポンシブLPです。

## 表示方法

`matcha-bloom/dist/index.html` をブラウザーで開いてください。

ローカルサーバーを利用する場合は Node.js で `node matcha-bloom/preview.cjs` を実行し、`http://127.0.0.1:4173/` を開きます。

## 構成

- `matcha-bloom/dist/index.html`：ページ本文
- `matcha-bloom/dist/style.css`：デザイン、レスポンシブ表示、アニメーション
- `matcha-bloom/dist/script.js`：ボタンの案内表示、リンク設定
- `matcha-bloom/dist/assets/parfait.png`：生成した商品イメージ

販売期間・価格・店舗情報は仮表記です。予約・注文・SNSのURLは `script.js` の `links` に設定します。
